# WF Companion 0.1.29

Game-folder selection now lists supported clients with their full installation paths, remembers your choice, and offers an optional folder step during first-time setup. Selecting a folder does not install addons or connect saved character data.

Inventory & Bank now explains missing, unrecorded, empty, filtered and unavailable saved data more clearly. Long character names wrap on Overview cards, item-search backgrounds are consistent, and the slimmer update banner keeps navigation accessible.

The bundle includes refreshed Forever Storage 0.7.0 asset notices and Forever Professions 0.1.4 artwork licensing/provenance documentation. Professions artwork uses CC BY 4.0; addon code remains GPL-3.0-only. Runtime code and artwork bytes are unchanged. Forever Core 0.7.0 / API 1 is unchanged.

Updating the companion does not automatically install addons or change game saves. Install addons from the Addons page when ready; existing addon files are backed up. WoW may stay open while copying. Reload updated addons manually; newly added addons or assets may require a full restart.

Saved inventory remains read-only and separate from manual plans. Automatic count replacement remains blocked. No Professions companion importer is added.

Beta has ended; outstanding live checks, including launch-client compatibility, remain pending. The installer is unsigned. SHA-256 checksums and dependency sources accompany this release.
