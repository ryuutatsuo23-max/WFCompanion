# WF Companion 0.1.20

Saved Beta characters now connect automatically when the companion finds one account folder in the usual installation location. A previously remembered folder is reused. Several account folders or a nonstandard installation still require selecting the intended folder.

Core-only characters can appear without a professions cache. While the companion stays open, newly saved characters and professions are checked every 30 seconds and accepted after two unchanged checks. Log into a character with Core enabled, then log out normally to save its data. No folder selection or Connect click is needed for an unambiguous discovered account. Saved observations are not live tracking.

Overview character cards now sit side by side when space permits and return to one column in narrow windows or with larger text. Existing manual profiles, plans and notes are preserved. Inventory eligibility remains separate and unchanged.

Automatic checks pause during open dialogs and when saved-game automatic checks are disabled. Forget saved connection disables automatic discovery until Connect is chosen again. Unavailable saves retain existing records.

Optional addon packages are unchanged. The optical bridge is not included. Personal data stays outside the program folder; the full installer remains available as a fallback. Publisher signing remains pending.
