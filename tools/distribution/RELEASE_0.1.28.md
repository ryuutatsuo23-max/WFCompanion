# WF Companion 0.1.28

Overview character cards now show saved Bags and Bank summaries from the same records as Inventory & Bank. Clicking Bags & Bank opens that character's saved inventory directly.

The Addons page now includes separate Forever Core, Forever Storage and Forever Professions entries. The bundle includes reviewed Forever Storage 0.7.0 and Forever Professions 0.1.4, with a distinct default Professions minimap position. Existing saved positions are preserved. Core 0.7.0 / API 1 is unchanged.

Updating the companion does not automatically install game addons or change game saves. Use the Addons page for addon installation; existing files are backed up. WoW can stay open during copying. Updated addons require a manual reload; newly added addons or assets may need a full game restart.

Forever Professions captures are not yet imported into the companion. Saved inventory remains read-only and separate from manual plans; automatic count replacement remains blocked.

Beta has ended. Live default minimap positioning, Professions Custom/Native behavior, readable guild-bank permission transitions, naturally earned level changes and launch-client compatibility remain pending.

The installer is unsigned. Dependency sources and SHA-256 checksums accompany this release.
