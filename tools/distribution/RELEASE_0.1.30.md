# WF Companion 0.1.30

Settings now includes a Saved game data panel. Find account saves in your selected game folder or choose WFCore.lua directly, then preview the characters and realms before connecting. Cancel keeps the existing connection unchanged. New connections require an explicit choice; remembered connections continue loading normally.

If a connected save is missing or moved, Settings explains how to recover it. Reconnecting a matching moved save keeps the existing character profiles and manual plans, with local recovery backups. Different character sets, realms or client identities are rejected instead of merging profiles.

Saved items and character details load from the remembered connection after reopening. Unavailable or unrecorded data remains clearly distinguished from empty inventory. Saved inventory is read-only; automatic count replacement remains blocked.

The addon bundle is unchanged from 0.1.29. Updating the companion does not install game addons or modify game saves. No Professions companion importer is added.

Beta has ended; release-client compatibility and outstanding live checks remain pending. The installer is unsigned. SHA-256 checksums and dependency source archives accompany this release.
