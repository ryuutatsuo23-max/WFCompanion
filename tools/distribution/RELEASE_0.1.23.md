# WF Companion 0.1.23

**Addons page:** install the bundled Bags & Bank addon and required Core from the Page dropdown. Detect or choose your client folder, compare installed files, and retain verified backups and exact-revision receipts. Different installed files require confirmation before replacement. Legacy combined-Core layouts are blocked before any addon files change; no automatic migration or save reset occurs.

**Saved Bags & Bank:** view linked saved snapshots directly, including recorded item names, quantities and capture times. Manual inventory is labelled separately. Partial scans show subtotals, and unopened banks remain Unknown. This read-only view does not change plans or enable automatic count replacement.

**Pinned addon bundle:** Forever Core 0.7.0/API 1 (4022228) and Forever Storage 0.7.0 (47d3e8f), including the Core welcome. Existing companion users can install/update these through Addons; updating the companion alone does not replace game addons.

Compatibility evidence covers Forever Beta 1.60.1 build 70532/interface 16001. Readable guild tabs and permission transitions remain untested; broader addon combinations and future game builds are not fully validated. These are documented limitations, not claims of complete live validation.

WoW can remain open during copying. Wait until installation finishes before /reload. Newly added addons/modules may require a full game restart. The companion never launches, closes or reloads WoW automatically. Personal saves and other addons are preserved.

This release uses the full installer because the bundle adds files. Publisher signing remains pending.
