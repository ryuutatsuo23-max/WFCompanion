# Privacy

WFCompanion stores character records, plans, inventory snapshots, settings and
local backups on the user's computer. It does not upload those records to the
maintainer. The optional addons use game addon APIs and WoW's SavedVariables;
they do not provide an Internet upload service.

Automatic stable-update checks contact the public GitHub API. They are enabled
by default and can be disabled under Settings, Companion updates. GitHub receives
ordinary network request information such as the IP address and a User-Agent
containing the WFCompanion version. Choosing Download update contacts GitHub's
release servers to obtain an installer and checksum. See GitHub's privacy policy:
https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

Checking local game data reads saved files on the user's PC; it does not send
character data to GitHub. No analytics, advertising or crash-upload service is
included. Files or screenshots users choose to post in GitHub issues are public
and subject to GitHub's policies; users should remove personal data first.

The uninstaller offers to retain or delete companion data. Retention is the
default. This option does not delete WoW SavedVariables. Third-party applications
and services have their own privacy policies.
