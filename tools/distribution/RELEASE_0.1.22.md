# WF Companion 0.1.22

Update and restart now offers **Save settings before updating**, checked by default. Confirming saves changed Settings before starting the update. Cancel leaves them untouched, and a save failure stops the update.

Unchecking the option leaves unsaved Settings blocking the update. Character and item editor drafts still need explicit saving; applied but unsaved records also block updates. The checkbox has extra room so its unchecked border and label remain fully visible.

A smaller update from 0.1.21 is available, with the full installer as fallback. Addon packages and saved-data integration are unchanged. Publisher signing remains pending.
