# Forever Storage — feedback

One problem or suggestion per report is easiest to follow. Short reports welcome!
Copy this template:

```text
Bug or suggestion:
Storage / Core versions:
Package revision (from the ZIP filename):
Game version / build:
Other bag addons enabled:
View: current bags / open bank / cached bank / saved character

Steps (for a bug):
Expected:
Actually happened:
Repeats: always / sometimes / once
Lua error or screenshot (if available):
```

If you tried Refresh or reload, mention whether it helped. You do not need to
reload just to submit feedback. For a count issue, include the item name and
the counts shown by Storage and the normal game UI.

For general feedback, simply tell us what felt useful, slow or confusing and
what you would change. You can skip fields that do not apply.

Remove personal details from screenshots and errors. Do not post your full WTF
folder, account details or saved-variable files publicly.
