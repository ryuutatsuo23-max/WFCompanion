# Forever Professions artwork

Original AI-generated artwork, approved by the user on 2026-10-23.
Style reference: the approved Forever Storage logo. The anvil, hammer, teal
cloth and gold infinity emblem identify professions without text.

- `forever-professions-logo.png`: original full-resolution artwork, unchanged.
- `forever-professions-icon.tga`: 64 x 64 RGBA, uncompressed TGA, Lanczos export.

The minimap and TOC IconTexture use the TGA basename. Both assets are included
in the independent Professions package allowlist and SHA-256 manifest.
The offline preview approximates Blizzard borders and uses the original PNG;
the owner confirmed the icon loaded on the Beta minimap and AddOn List without
Lua errors. Minimap interaction and reload persistence were also confirmed. These
results apply to Beta 1.60.1.70532, not the release client. Release-client icon
loading/readability and all Custom/Native mode lifecycle checks remain PENDING
LIVE. Beta is unavailable; no new live checks are claimed.
